# NetQuerry 🌐

An AI-Powered Assistant for Computer Networks - A local, privacy-first Retrieval-Augmented Generation (RAG) chatbot designed to answer questions about computer networking concepts. Powered by Ollama (Gemma3 4B), LangChain, and Streamlit with a cybersecurity-themed UI.

---

## Features
- **Accurate, context-based answers:** Only responds using information from the provided computer networking PDFs.
- **Multi-topic support:** Dynamically selects between different networking topics (Cisco, Computer Networks, etc.) with automatic database building.
- **Modern Cyber-themed UI:** Matrix-inspired ChatGPT-style interface with neon green accents and terminal aesthetics.
- **Private & Local:** No data leaves your machine. Runs fully offline with Ollama.
- **No Hallucination:** Strict prompt and retrieval settings to avoid made-up answers.
- **Intelligent References:** Automatically cites page numbers from source PDFs.
- **Chat Logging:** All interactions are logged to `chat_logs_output.csv` with response times.

## Quickstart

### 1. Prerequisites
- Python 3.10+
- [Ollama](https://ollama.com/) installed and running locally
- Required Ollama models:
  - `ollama pull gemma3:4b` (for text generation)
  - `ollama pull nomic-embed-text` (for embeddings)

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Prepare your data
- Place your computer networking PDFs in topic-specific folders inside `data/`:
  - `data/Cisco/` - Cisco networking materials
  - `data/Computer Networks/` - General networking concepts
  - Add more topic folders as needed
- The app will automatically detect and list all available topics.

### 4. Start the chat UI
```bash
streamlit run app.py
```
- Open [http://localhost:8501](http://localhost:8501) in your browser.
- Select a networking topic from the dropdown.
- The vector database will be automatically created on first use for each topic.

### 5. (Optional) Pre-populate databases
```bash
python populate_database.py --reset
```
This manually populates the default `chroma/` database. Topic-specific databases are auto-generated by the app.

## Usage
1. **Select a Topic:** Choose from available networking topics in the dropdown menu.
2. **Ask Questions:** Type questions like:
   - "Explain TCP/IP protocol"
   - "What is the OSI model?"
   - "How does DNS work?"
   - "Describe VLAN configuration in Cisco"
3. **Get Answers:** The AI responds with context-based answers and includes page references from source PDFs.
4. **View Logs:** Check `chat_logs_output.csv` for interaction history and performance metrics.

---

## Technical Details
- **LLM Model:** Gemma3 4B via Ollama
- **Embedding Model:** nomic-embed-text via Ollama
- **Vector Database:** ChromaDB with persistent storage
- **Chunk Settings:** 1500 characters with 200 character overlap
- **Retrieval:** Top 3 most similar chunks (k=3)
- **UI Framework:** Streamlit with custom CSS styling

---

## Troubleshooting
- **Ollama not found:** Ensure Ollama is installed and running (`ollama serve`).
- **Model not found:** Run `ollama pull gemma3:4b` and `ollama pull nomic-embed-text`.
- **No answers returned:** Ensure your PDFs are in `data/<topic>/` folders. Databases auto-build on first query.
- **Empty topic dropdown:** Create topic folders inside `data/` and add PDF files.
- **Slow first query:** Vector database is being built automatically; subsequent queries are faster.
